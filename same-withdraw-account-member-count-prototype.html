    一、改造页面
    📌 本说明书只写业务规则本身。页面的样子和交互直接看原型，红色 NEW 是新增，橙色「改」是调整。
    页面改动点
    风控管理 → 相同提现账号（5 个页签都改）列表新增列「绑定会员数」，点击展开按会员汇总；「绑定会员数」「累计绑定次数」「最近绑定时间」表头可点击排序；新增筛选「绑定会员」；「绑定次数」筛选的默认值和列表默认排序调整；导出增加「绑定会员数」
    二、功能描述与业务规则
    🎯 核心结论
    列表直接显示每个账号被几个不同会员绑定过，不用点开明细
    打开页面默认只看被 2 个及以上会员绑定过的账号，按会员数从多到少排
    01绑定会员数核心：历史绑定过该账号的不同会员 ID 个数，与展开绑定明细里「历史绑定过 N 个会员」口径相同（绑定明细里出现过的会员都算，含绑定、解绑、修改的记录）。放在「累计绑定次数」前面。
    02两个数字各自展开核心：
    点击展开内容
    绑定会员数按会员汇总，一个会员一行：会员ID、会员账号、收款人姓名、绑定次数（该会员绑定这个账号的次数）、最近绑定时间、当前在绑（是 / 否，与「当前绑定会员」列同口径）；按最近绑定时间倒序
    累计绑定次数现有绑定明细，不变
    同一个账号同一时间只展开一种：点另一列切换，点同一列收起。按会员ID查询时，该会员所在行高亮，与绑定明细一致。
    03筛选核心：新增筛选「绑定会员」（按绑定会员数筛），选项 ≥1 人（全部）、≥2 人、≥3 人、≥5 人，默认 ≥2 人。「绑定次数」选项不变，默认值由 ≥2 改为 ≥1（全部）。两个筛选同时生效，都满足才显示；「重置」后回到默认值（绑定会员 ≥2 人，绑定次数 ≥1）。
    填了会员ID或提现账号时，这两个筛选不生效（置灰），显示该会员或该账号的全部结果；清空后恢复生效。
    04排序核心：
    项规则
    默认排序先按绑定会员数从多到少，相同的再按累计绑定次数从多到少，再按提现账号
    表头排序「绑定会员数」「累计绑定次数」「最近绑定时间」三列可点击表头排序：第一次点击按从多到少（时间从新到旧），再点切换为从少到多（时间从旧到新）；该列相同的再按默认排序
    生效范围排序作用于全部查询结果，不只当前页；点「查询」、翻页、切换页签保持当前排序，点「重置」恢复默认排序；导出按当前排序
    05导出：增加「绑定会员数」列，位置与列表一致；按当前筛选（含新筛选）和当前排序导出。绑定明细不变。
    06从黑名单页跳转：从「提现账号黑名单」页点「绑定历史」跳转过来时，精确查询该账号并展开绑定明细；因为带了提现账号，按 03 显示全部结果。
    三、限制条件
    项说明
    统计范围绑定会员数以绑定明细为准，明细开始记录之前已解绑的会员不计入
    四、开发注意事项
    1. 列表本来就是把绑定明细按账号汇总出来的，在同一个汇总里多加一个「不同会员 ID 计数」即可；会员 ID 已在现有索引里，不需要另外查。
    2. 会员ID 或提现账号有值时，后端查询忽略「绑定会员」「绑定次数」两个条件（导出同理），前端把两个下拉置灰；从黑名单页跳转进来不用再单独改这两个筛选的值。
    3. 表头排序在后端做（排序字段和方向随查询、翻页、导出一起传），作用于全部结果，不能只排当前页。
    4. 绑定会员汇总从同一份绑定明细按会员归总即可；「当前在绑」和列表「当前绑定会员」用同一个来源（会员现有的提现账号）。
    5. 只改这个页面的列表、筛选、排序、导出和新增的会员汇总；绑定明细、拉黑、解除等其他功能都不动。
