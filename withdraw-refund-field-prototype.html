会员详情 · 新增「提现退回」字段PRD 需求说明 v1.0 · 2026-07-30
✕
一、改造页面与字段

改造页面：V1 后台 → 会员管理 → 用户详情弹窗。

新增字段：在「充值提现」区块新增一项 提现退回，展示次数 / 金额两个值（格式与「人工充值 0/0」「累计充值 0.00/0」一致）。

字段展示格式口径
提现退回次数 / 金额
例：3 / 1,250.00		该用户历史所有提现申请被驳回或出款失败、金额已退回余额的记录：笔数汇总为「次数」，退回本金汇总为「金额」。

位置：置于「充值提现」区块，与「充值优惠券奖金总额」同一行右侧（见原型黄色高亮处）。

二、口径与边界
问题取定 / 建议
退回包含哪些类型 需拍板推荐 提现退回 = Type IN (6 出款失败退回, 9 审核拒绝退回)。
金额口径取账变金额 ChangeAmount＝实际退回用户余额的钱（用户真实拿回的金额）；与「累计提现手续费」互不重复。
次数含义一笔退回账变 = 1 次；部分退回（差额退回）也各计一条，比按提现单状态更贴近真实退款事件。
数据时效与账变同步实时汇总统计。
时间范围跟随弹窗「开始/结束时间」，与现有奖励字段同一套时间处理逻辑。
三、验收标准

1. 用户详情「充值提现」区显示「提现退回」，格式 次数 / 金额，金额保留 2 位小数、千分位。

2. 数值 = 账变 Type IN (6,9) 的次数与金额。

3. 无退回时显示 0 / 0.00，不报错、不留空。

4. 受弹窗时间筛选影响，行为与本页其它活动奖励字段一致。
