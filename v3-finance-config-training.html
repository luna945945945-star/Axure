充提配置入门手册

V3 中台 → 财务管理：充值类型管理 · 提现类型管理 · 本地收款账号管理
新人自学用配合后台页面对照看每节末尾有自测

这份手册怎么用

建议打开后台，一边看手册一边把对应页面点开对照。看完你应该能做到三件事：

  1. 说清楚大类、通道、本地收款账号三者是什么关系；
  2. 独立看懂这三个菜单里每一列、每一个字段的含义；
  3. 会员反馈"充不了 / 提不了"时，知道按什么顺序去查。

手册不覆盖具体的开通流程和审批规则，那部分以团队实际规范为准。

1先搞清楚这几个页面的关系

这套配置涉及好几个页面，先理清谁管谁，后面看每一页都会轻松很多。
① 通道字典
系统里所有能用的通道母表，由总控维护，商户只能挑、不能加。
在「充值配置」「提现配置」两个菜单里。
② 支代付三方管理
公司在某家三方支付商开的账户，存着商户号和密钥。同集团下多个商户可以共用同一个账户。
↓　两者组合，才配得出一条真正能用的通道　↓
③ 充值大类 / 提现大类
会员在前台看到的分类入口，比如 UPI、本地银行卡、USDT。
④ 充值通道 / 提现通道
挂在大类下面、真正干活的那条路，一条通道绑一个三方商户。
⑤ 本地收款账号
本地类大类用的是公司自己的银行卡、UPI、USDT 地址、电子钱包，不走三方。
↓　会员端　↓
⑥ 会员充值 / 提现
会员只看得见"大类"。选完金额下单后，系统自动在这个大类下面挑一条通道或一个收款账号，会员不选具体走哪家。
大类是"会员看得见的分类"，通道是"分类下面真正干活的那条路"。会员只选分类，走哪条路由系统自动分配。

本手册覆盖的三个菜单

菜单里面有什么
充值类型管理两个子页签：充值大类 + 充值通道
提现类型管理两个子页签：提现大类 + 提现通道
本地收款账号管理四个页签：本地银行卡账号 / 本地 UPI 账号 / 本地 USDT 账号 / 本地 EWallet
「充值配置」「提现配置」这两个菜单是通道字典，是总控维护的通道母表（页面上连新增按钮都没有），和日常要配的"充值通道 / 提现通道"不是一回事，名字很像但别点错。
配置有先后顺序：先有三方商户，才配得出通道；先有大类，通道才有地方挂。顺序反了，新增时下拉里会什么都选不到。
  1. 会员在充值页上看到的那一排入口，是大类还是通道？
  2. "充值配置"和"充值类型管理 → 充值通道"分别是什么？

2充值类型管理 → 充值大类

财务管理 → 充值类型管理 → 充值大类　这里配的是会员充值页上那一排分类入口。列表顶部的"商户"是必选项，先选商户才有数据。

三个重点字段

字段说明
内置充值大类新建时必须选一个系统预设类型（三方法币、本地银行卡、三方 USDT、本地 UPI、本地电子钱包、本地 USDT、三方银行卡、AR Pay 等，以页面下拉为准）。类型决定这个大类下面挂什么——三方类挂通道，本地类挂收款账号。建完不能改，编辑时这一项是灰的，选错只能删了重建。
数量限制同一个商户，三方法币类型最多建 8 个（所以能出现 UPI、Paytm、PhonePe 这样多个并排的入口），其它类型各只能建 1 个。
快捷充值金额会员充值页上的"一键选金额"按钮。每一行是：金额 + 赠送类型 + 赠送数额。条数有上限，超出会提示"最多配置 N 条快捷金额"；只剩一行时删除按钮是灰的。金额必须大于 0、不能重复。
充值的赠送配在大类层，手续费配在通道层。这两个位置经常被记反。

其余字段

  • 选中前 / 选中后图标：前台图标的两种状态，要求 70×70，jpg/png/webp。
  • 前台显示名称：会员看到的名字，可以随时改。
  • 排序：决定前台入口的先后顺序。
  • 会员最大待支付单数：一个会员同时能挂多少笔未支付订单，填 0 = 不限制，列表里也会显示"不限制"。用来防刷单。
  • 状态：不在编辑弹窗里，只能在列表上用开关切换，切换时有二次确认。关掉后会员前台直接看不到这个入口。
  • VIP 充值赠送：列表里的另一个开关。
    开启后，该大类充值成功将按会员VIP等级比例发放VIP充值等级奖励

每一行还有一个【充值通道管理】按钮，点了会直接跳到充值通道页，并自动带上这个大类的筛选条件。

  1. 一个商户最多能建几个"三方法币"类型的大类？其它类型呢？
  2. 某个大类的状态开关在哪里切？编辑弹窗里能改吗？

3充值类型管理 → 充值通道

财务管理 → 充值类型管理 → 充值通道　整套配置里最容易配错的一页，建议重点看。

新增一条通道的顺序（下拉是层层联动的）

  1. 选商户。不选商户，下面的三方映射码是灰的。
  2. 选三方映射码（哪一家三方）。不选它，通道名称是灰的。
  3. 选通道名称。这是个级联选择，按三方商户分组，每条还标着已绑定 / 未绑定——已绑定表示这条通道该商户已经配过。
  4. 通道币种会自动带出，只读不能改。
  5. 选充值大类（挂到哪个入口下），填前台显示名称（会员看到的通道名）。
  6. 填轮询权重、可见等级、可用时间段、充值金额区间，需要时填手续费。
  7. 保存后用行内【代收测试】验证这条通道能不能正常拉起支付。
编辑一条已有通道时，商户、三方映射码、通道名称、充值大类都是灰的，改不了。这是刻意做的限制，防止改完之后通道挂错到别家三方去。要换只能删了重建。

列表上有两个"状态"列，不要混

列是什么取值
状态本商户自己对这条通道的开关，可以点启用 / 禁用
可用状态上游是不是可用，只读。判定顺序：先看总控，再看三方商户可用 / 总控通道关闭 / 三方商户关闭
自己这边开着、但"可用状态"是红的，会员照样用不了。最常见的原因是三方商户号被禁用，它下面所有通道被系统自动关掉。

会员下单时，系统按 5 个条件挑通道（必须同时满足）

#条件说明
①状态是启用，且"可用状态"是可用最常见的"通道怎么不见了"
②充值金额落在通道的金额区间内会员充 50，通道最小 100，就轮不到它
③当前时间在通道的可用时间段内配了 08:00~23:59 的通道，凌晨不出
④会员的充值等级在"可见等级"里留空 = 所有等级都可见
⑤轮询权重大于 0同一大类里只要还有权重大于 0 的通道，权重为 0 的那条就分不到订单

两个权重的区别

列表"轮询权重"这一格是上下两行：上面是预设权重（人工配的），下面是实时权重（系统根据这条通道近期表现自动打折算出来的）。同一大类下多条通道按权重比例分配，权重越大越容易被分到。实时权重掉到 0，说明系统已经临时把它降下来了，这时应该去查通道是不是在报错。

成功率统计这一列

成功率统计 = 近10分钟/近30分钟/近1小时/近24小时 [成功订单状态数/所有状态数量]

手续费

针对越南部分通道如充值卡，会员充值时根据预设手续费扣除。请填写 0~1 之间的小数，如 0.25 表示 25%；以充值 1000、手续费 0.25（25%）为例，实际到账 750。
  1. 一条通道"状态"是启用、但"可用状态"显示"三方商户关闭"，会员能用它吗？该去哪里处理？
  2. 预设权重和实时权重有什么区别？实时权重是 0 意味着什么？
  3. 编辑一条通道时，哪几个字段改不了？为什么这么设计？

4提现类型管理 → 提现大类

财务管理 → 提现类型管理 → 提现大类　结构和充值大类对称，但费率和时间段配在这一层，这是和充值最大的差别。
这一页没有新增按钮，只有编辑——提现大类由系统内置大类派生，商户只能改配置、不能自己加。页面顶部另有一个【今日提现总次数配置】，配的是这个商户当天的总次数上限，和每个大类里的"每日提现次数"不是一回事。
字段说明
内置提现大类系统预设类型（银行卡、UPI、USDT、电子钱包、PIX、WavePay、KBZPay、AR Pay、Easypaisa、JazzCash、快速 UPI 等，以页面为准）。编辑时是灰的。
提现费率（%）手续费在大类层配，填 0.10 表示 0.1%。
收取费率金额范围
即单笔提现多少范围内，会收取手续费，为空则表示不限制
每日提现次数单个会员每天能提几笔。
最小 / 最大提现金额单笔金额范围。
快捷提现金额前台一键选择的按钮，可配多个。
可用时间段配在大类层，下面的通道跟着继承。充值不是这样——充值的时间段配在通道上。
提现提示前台展示的一句提示文案。
充值：赠送在大类、手续费在通道。提现：费率和可用时间段都在大类。
  1. 要调整某个提现大类的手续费，去哪一页改？
  2. 提现的可用时间段配在大类还是通道？充值呢？

5提现类型管理 → 提现通道

财务管理 → 提现类型管理 → 提现通道　配置方式和充值通道基本一样（同样是商户 → 三方映射码 → 通道名称层层联动，编辑时这几项也改不了），下面只讲提现独有的部分。

提现独有的字段

字段说明
自动出款权重自动出款时按权重分配。填 0 = 不参与自动出款，但人工审核时仍然可以手动选它——这点和充值通道的权重 0 不一样。
自动关闭阈值
通道余额低于配置的阈值则自动关闭
是否整百提现选"是"，会员提现金额必须是 100 的倍数。
三方通道余额弹窗里只读展示。列表上则是"通道余额"一列，上下两行：余额 + 最后更新时间。
通道余额最后一次的更新时间
这个余额是系统定时同步的，不是打开页面实时查的，所以判断数据新不新要看更新时间。
出款显示名称会员看到的通道名。
操作人员重新对通道自定义的名称
自动关闭是单向的：余额补回来以后通道不会自动重新打开，必须人工到列表里手动启用。补完款以为就好了、结果通道一直关着不出款，是最常见的失误。

代付测试

每行有【代付测试】按钮，里面有四块：查询通道余额、代付拉单测试、代付订单查询、代付回调测试。日常用得最多的是查询通道余额。

提现的筛选条件比充值多，除了状态、金额区间、权重，还要看是否整百、大类归属、大类上的可用时间段。

  1. 某条提现通道自动关闭了，补款之后需要做什么？
  2. 自动出款权重填 0，人工审核时还能选这条通道吗？

6本地收款账号管理

财务管理 → 本地收款账号管理　四个页签：本地银行卡账号 / 本地 UPI 账号 / 本地 USDT 账号 / 本地 EWallet。这是本地类大类专用——会员转账到的是公司自己的账户，中间没有三方。

和三方通道的区别

对比三方通道本地收款账号
钱到哪先到三方账户直接到公司自己的账户
挂在哪三方类大类下本地类大类下
要不要三方商户要不要，只跟商户走
靠什么控制分配轮询权重 + 金额区间 + 可见等级 + 时间段金额区间 + 充值等级 + 日总笔数 / 日总限额
怎么到账三方回调自动到账会员转账后提交，由后台确认或系统匹配

关键字段

  • 商户：编辑时不可改。
  • 收款信息：银行卡页签是 银行名称 / 持卡人 / 银行卡号 / 支行 / IFSC Code / 二维码；UPI 页签是 UPI 账号；USDT 页签是 网络协议 / 钱包地址 / 二维码；EWallet 页签是 钱包类型 / 持卡人 / 手机号。这些信息填错等于钱收不到，保存前务必双人核对。
  • 自定义昵称：内部识别用，不展示给会员。
  • 单笔金额限制：最小 / 最大。会员充值金额不在范围内，就不会分到这个账号。
  • 【固定】日总笔数 / 【固定】日总限额：这张卡一天最多收几笔、多少钱。列表里有一列日限制统计（今日已收 / 日限制），格子里直接写着"限制笔数：x / y""限制金额：x / y"。用满当天就不再往这张卡分配，第二天重置——这是本地账号独有的，三方通道没有。
  • 充值等级：多选。
    （不勾选表示任何等级都可见）
  • 排序、备注、状态：状态关掉后不再往这张卡分配新订单，已经下单未支付的不受影响。
要换卡或改账号信息：先把旧账号禁用，确认没有在途订单再改。直接改号可能出现"会员按旧号转了钱、系统按新号对账"的坏账。
  1. 某张收款卡今天一直没收到订单，有哪几种可能？
  2. 本地收款账号靠什么控制"今天最多收多少"？

7新人最容易犯的 8 个错

  1. 顺序搞反：先建通道后建大类，新增时下拉里什么都选不到。正确顺序是 三方商户 → 大类 → 通道。
  2. 建完才发现类型选错：大类的内置类型，通道的商户 / 映射码 / 通道名称 / 所属大类，建完都改不了，只能删了重建。
  3. 权重填 0 就以为配好了：同大类里还有权重大于 0 的通道时，权重 0 的那条一单也分不到。
  4. 只看自己那个开关：还要看"可用状态"这一列，上游关了照样不可用。
  5. 赠送和手续费记反：充值赠送在大类、手续费在通道；提现费率在大类。
  6. 跑到通道上找提现时间段：提现的可用时间段在大类，通道继承。
  7. 补完款没手动开通道：被自动关闭阈值关掉的提现通道不会自动恢复。
  8. 直接改本地收款账号的卡号：要先禁用、确认无在途订单再改。

8排查清单：会员说"充不了 / 提不了"

会员看不到某个充值方式

  • 大类的状态是不是关了
  • 大类下面有没有可用通道（本地类看有没有可用的收款账号）
  • 通道的"状态"和"可用状态"是不是都正常
  • 通道权重是不是 0
  • 会员的充值等级是不是不在"可见等级"里
  • 当前时间是不是不在通道的可用时间段内

某条通道一直没有订单

  • 预设权重是不是太低；实时权重是不是被系统降到 0（说明近期失败较多）
  • 金额区间是不是把常见充值金额挡在外面
  • 可见等级是不是限制得太窄
  • 本地收款账号还要看：日总限额、日总笔数是不是已经用满

提现通道突然不出款

  • 通道余额是不是低于自动关闭阈值，被系统自动关了
  • 补款之后有没有人工重新启用
  • 自动出款权重是不是 0（这种情况只能人工出款）
  • 金额是不是不符合整百提现或金额区间
  • 大类上的可用时间段是不是已经过了
