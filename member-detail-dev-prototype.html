需求说明 · V3 会员详情改版（审核概况 + 9 页签）✕

原型上带红色 NEW 的是 V3 现在没有、需要新做的字段或功能；没标的是 V3 已有、只调整了位置或展示方式。字段名称一律沿用 V1 原名。

一、改造范围
页面 / 位置改动
V3 中台会员详情弹窗（会员列表、充值订单、提现订单、出款审核等所有入口共用）①弹窗尺寸不变（最宽 1500px），标题栏会员ID 后面加全屏图标，用户自己切全屏 / 退出全屏；多会员 ID 标签从标题栏下面单独一行挪到查询条「查询」按钮后面，省一行。②页签从 6 个改为 9 个，原「基本信息」页签由「审核概况」替代。③原标题栏右侧「改状态 / 改备注 / 改打码量」三个按钮去掉，改为审核概况表格内对应字段旁的「修改」按钮。④标题栏、查询条照 V3 现有样式。
V1 老后台会员详情不改（待确认）

七、行业常规与注意点
· 同类后台（出款风控 / 会员 360 视图）的常见做法是「首屏一页看完钱 + 风险，明细再进页签」，本方案一致。审核员最常看的三类信息：充提差和彩金占比（是否套利）、打码是否达标、关联账户和新增取款账户（是否多开 / 盗号），都放在首屏。这是经验判断，不是调研结论。
· 「会员近期操作记录」和「取款账户 添加不到 3 天标红」是常见的盗号出款提示，3 天是经验值，待风控确认。
· 关联账户数超过 3 标红是演示阈值，建议做成商户可配置（待确认）。
· 最后登录浏览器指纹：V1 代码里没找到存储，判断是没有采集；如果确实没有，风控信息里这一行先不做。
八、多国家 / 多币种注意
项说明
金额小数位按商户币种显示（INR 2 位；越南盾等小币种通常 0 位、金额很长）。大表每格宽度固定，小币种长金额要实际站点数据再验一次
取款账户类型按币种显示对应类型：印度 银行卡（IFSC）/ UPI；巴西 PIX（CPF / 手机 / 邮箱 / 随机密钥）；越南等 银行卡；USDT 地址。表头「持卡人姓名 / 卡号 / IFSC（UPI ID）」要随币种换成对应名称
充值类型PhonePe、UPI 快捷等是印度的，其他国家按当地支付方式显示，取现有数据即可
时区所有时间按商户时区显示，和 V3 现有页签一致（表头带 UTC+N 的照旧）
语言文案走 V3 语言包。原型右上角的中英文切换已测：英文下 1500 宽弹窗大表标签格会换成两行（不截断），概况需要往下滚一点。其他语种（越南语、葡语较长）上线前要再看一次
KYC / 监管本需求不涉及 KYC 字段；如某些国家要求展示实名信息，另提
