需求一：会员列表「导入批量操作」支持会员账号
改造页面改动点
会员管理 → 会员列表 → 导入批量操作模板、校验结果表加「会员账号」列；模板升级 V6
🎯 核心结论
会员ID、会员账号填一项即可；两个都填必须是同一个会员
01定位会员核心：只填会员ID按ID；只填会员账号按账号；两个都填必须是同一个会员；两个都没填判失败（整行空的忽略）。
02账号匹配核心：去掉空格和开头的 + 后，与会员账号完全一致（不区分大小写）才算匹配；不补也不去区号和开头的 0。科学计数（如 9.19999E+11）判失败。
03失败提示：
情况提示
两个都没填会员ID和会员账号不能同时为空
会员ID不是数字或超出范围会员ID格式不对，账号请填在「会员账号」列
科学计数会员账号被 Excel 转成了科学计数，请把账号列设为文本后重新填写
账号查不到会员账号不存在
两个不是同一会员会员ID与会员账号不是同一会员
同一会员多行与会员ID【xxx】重复
04重复：按定位到的会员判断（一行填ID、一行填账号也算）；只在其他校验都通过的行之间比，第一条通过，后面的判失败。
05结果表：「会员账号」列在「会员ID」后。通过的行「会员ID」显示定位到的ID；失败的行显示文件原值。
06模板 V6核心：A 会员ID（与账号二选一）、B 会员账号（与会员ID二选一，文本格式），其余列顺移；示例行一行只填ID、一行只填账号（910000000000）。第二列表头不是「会员账号」的整份不导入，提示「导入模板已更新，请重新下载模板后导入」。
限制条件
项说明
未注册只处理已注册会员；未注册号码的拦截见需求三
匹配范围只按登录账号匹配，不按绑定手机号
条数每次最多提交 3000 条
开发注意事项
  1. 复用人工充值批量导入的「账号 / 会员ID 二选一」逻辑，与需求二共用；文案以本说明为准，科学计数不还原。
  2. 上传校验时把账号换成会员ID，提交、权限、日志仍按会员ID走。
  3. 现在首列为空会报错、统计条数也只看首列，都改成两列都空才算空。
  4. 结果表按列位置填值，加列后后面各列位置都要改。
  5. 模板改名 V6，下载链接同步改。
需求二：会员活动黑名单「批量导入」支持会员账号
改造页面改动点
系统管理 → 会员活动黑名单 → 批量增加模板、通过表、失败表加「会员账号」列；模板升级 V3
🎯 核心结论
会员ID、会员账号填一项即可，规则同需求一；可以只用手机号批量禁领红包等活动
01定位、匹配、失败提示核心：同需求一 01~03，区别是会员ID查不到提示「会员ID不存在」、重复提示「会员ID重复」。活动类型、备注的现有校验不变。
02重复核心：同一会员 + 同一活动类型算重复；同一会员同时有 -1 和具体类型也算重复。只在其他校验都通过的行之间比（「活动黑名单信息已存在」的行不参与），第一条通过。
03结果表：同需求一 05。填 -1 的行照现在展开成该会员未拉黑的各活动一行，每行都带会员账号。
04模板 V3核心：A 会员ID*（与账号二选一）、B 会员账号*（与会员ID二选一，文本格式）、C 活动禁止类型*、D 备注*；C、D 表头说明文字照旧；加一行只填账号的示例（910000000000）。旧模板处理同需求一。
限制条件
项说明
未注册 / 匹配范围同需求一
拉黑范围只处理本人，不带下级
条数每次最多 15000 条
开发注意事项
  1. 与需求一共用账号定位逻辑。
  2. 「保存提交」按列位置取会员ID、活动类型、备注，加列后取值位置要改。
  3. 模板改名 V3，下载链接同步改。
需求三：风控管理新增「手机号黑名单」
改造页面改动点
风控管理 → 手机号黑名单（新页面，放在「提现账号黑名单」后）查询、添加、批量导入（粘贴 / Excel）、删除、批量删除
前台 注册 / 绑定手机 / 更换登录手机号名单内号码被拦
🎯 核心结论
名单内号码不能注册、不能绑定、不能改成登录手机号；未注册的号码也能提前加入
号码已属于会员的，加入时同步拉黑该会员并踢下线
01号码统一核心：去掉非数字字符后统一为「区号 + 号码」，所有录入、查重、查询、前台比对都按这个写法。
填写（+91 站）统一为
+91 9811122233、91-98111-22233、0091 9811122233919811122233
9811122233919811122233（补站点区号）
09811122233、91 09811122233919811122233（去掉号码前一个 0）
位数校验和前台注册一致；多区号站点必须带区号。
02前台拦截核心：
操作命中时
注册发注册验证码时拦（不发短信），提交注册时再拦。提示「This phone number cannot be used to register」
绑定 / 换绑手机给新号码发验证码、提交时拦。提示「This phone number cannot be bound」
更换登录手机号提交时拦，提示同上
登录、忘记密码不查名单
提示不提黑名单；注册过和没注册过的号码，提示相同。
03已注册号码核心：号码等于会员的登录账号或绑定手机时，照样加入，并处理所有命中的会员：正常的设为拉黑并踢下线（记「本名单拉黑」）；已拉黑的不动（记「加入前已拉黑」，列表灰色）。会员是代理时结果里标出「代理，下级 N 人」。
04添加 / 批量导入：
方式规则
添加一个号码 + 备注（选填，≤500 字）；格式错误、已在名单在弹窗内提示
粘贴手机号一行一个，≤1000 个，超出不保存；备注共用；空行忽略
上传Excel模板「手机号*（文本格式）、备注」，≤15000 条、≤4M；第一列表头不是「手机号」提示「模板不正确，请下载模板后导入」。先逐行校验显示结果，保存只提交通过的行
跳过 / 失败原因手机号为空、格式错误、科学计数、已在黑名单、本次重复（只在其他校验都通过的行之间比，第一条通过）、备注过长
保存结果新增几条、同步拉黑哪些会员；粘贴方式另列已在名单 / 重复 / 格式错误的号码，Excel 方式另列未导入条数
05列表：手机号、关联会员ID、备注、创建时间、操作人、操作；按创建时间倒序，每页 20 条。查询：手机号（能统一的精确查，否则按数字包含查）、创建时间区间。
06打码：没有本页「查看手机号」权限时，页面和提示里的号码都中间打码（如 9198****2233）；操作人自己填的原文照显示。
07删除核心：单条或勾选批量删除（≤200 条），删除后号码恢复可注册、绑定。关联会员中「本名单拉黑」且没被其他记录关联的，确认框可勾「同时解除这些会员的拉黑」，默认不勾。
08权限与日志：新增权限位 查看、新增、删除、查看手机号。添加、导入、删除写系统日志（号码、关联会员ID、是否同步拉黑 / 解除、操作人）。
限制条件
项说明
站点范围每个站点单独维护
不受限制后台添加会员、后台改会员手机号；邮箱注册（之后绑定名单号码会被拦）
换号换新号码注册拦不住
开发注意事项
  1. 号码比对复用提现账号黑名单的「带不带区号 / 前导 0 互认」做法，后台和前台用同一个方法。
  2. 发验证码只拦「注册验证」「绑定手机号」两种用途（换绑时给旧号码发的不拦）；提交拦注册、绑定手机、更换登录手机号三个接口。注册放在手机号格式校验后、验证码校验前。
  3. 发验证码接口对已注册号码会伪装成功，名单判断放在频率限制之后、伪装之前。
  4. 前台读缓存，缓存不可用时回查库，不能默认放行；上线前先全量加载。
  5. 同步拉黑复用会员列表批量拉黑（删登录令牌踢下线）。前台两条提示补多语言。
