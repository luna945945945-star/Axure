一、改造页面
📌 本说明书只写业务规则本身，样子和交互直接看原型，带红色 NEW 角标的是新增。
页面改动点
会员管理 → 会员列表新增筛选「累计充值金额」（最小 ~ 最大）；「充值金额」列头加排序箭头；导出带上新筛选和排序
二、功能描述与业务规则
🎯 核心结论
「累计充值金额」筛选的数就是列表「充值金额」列的数：成功到账的充值本金，不含赠送、红包
只填最小 = 大于等于，只填最大 = 小于等于，两格都填 = 区间；与充值次数 / 未登录天数 / 流水倍数 / 总盈亏四组同一套
「充值金额」列头可排序：降序 → 升序 → 取消，同一时间只有一列生效，与保险箱余额 / 余额 / 打码量同一套
01筛选口径核心：按列表「充值金额」列的数筛，没充值过的会员按 0 算。只填最小 = 大于等于最小；只填最大 = 小于等于最大；两格都填 = 最小到最大（含两端）。最小大于最大不查询，提示方式同现有四组。
填法查出来的会员
0 ~ 100充值金额不到 100 的，含从未充值
10000 ~ （不填）充值金额 10000 及以上
（不填） ~ 0从未充值
02排序核心：点「充值金额」列头循环 降序 → 升序 → 取消；同一时间只有一列生效，点别的可排序列直接切换；取消后回默认的注册时间倒序。同值按会员ID从大到小；没充值过的按 0 参与排序。
03导出核心：带上累计充值金额条件，与其他筛选一起生效；选了「充值金额」排序时，导出行序与列表一致。
04输入：只允许 0 和正数，最多两位小数。
05重置：点「重置」清空两格，排序一并取消。
三、限制条件
项说明
口径只算成功到账的充值本金；平台赠送、红包不算
范围只做老后台会员列表；代理后台不涉及
四、开发注意事项
  1. 列表查询、导出两处都要加新条件；导出是单独收集筛选值的，别漏；排序值也一起带过去。
  2. 没有充值记录的会员这个金额是空的，筛选和排序都按 0 处理：填 0 ~ 100 要能查到从未充值的会员，升序时他们排最前。
  3. 可排序列的白名单里加上「充值金额」；导出按列头排序时的本地排序也要支持这一列。
  4. 现有四组问号提示里写的「填一格 = 精确」与实际不符，一起改成「只填最小 = 大于等于，只填最大 = 小于等于，两格都填 = 区间」。
  5. 新筛选查得慢的话，在存会员累计充值金额的表上加索引。
