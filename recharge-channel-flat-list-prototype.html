二、功能描述与业务规则
00通用约定
  • 「V3 模式站点」= 已切到中台下单 / 出款的站点；06、10 只对这些站点生效。
  • 页面字段、文案、列顺序、单元格写法以原型为准；本文写「不变」的，沿用现有逻辑和校验，不新增代码。
  • 本次新增的提示文案、按钮、列名，要和现有页面一样补齐多语言。
01充值通道列表
  • 一条通道一行，条数、分页按通道算。「商户」列整页合并；按大类合并的「充值大类」列改成文字列，放在名称列后；名称列「前台显示名称」在上；「通道编码」列挪到「充值通道奖励」前。其余列不变。
  • 排列：没选充值大类时按通道 ID 倒序；选了大类时只列挂了该大类的通道，按该大类内的排序。
  • 「充值大类」列：所挂大类名称按充值大类页签的排序、英文逗号分隔；已关闭的大类加「（已关闭）」并置灰；筛选的大类加粗。
  • 「内置充值大类」列：位置不变，显示所挂大类的内置大类，去重。
  • 「充值通道奖励」：挂 1 个大类时和现在一样。挂多个大类时只算开启的大类：
    · 通道奖励：自定义比率 ≤ 每一个大类奖励时红字「不生效」，只对部分大类不生效时不提示；
    · 生效奖励：写区间「最低~最高」，每个大类按 max(大类奖励, 通道自定义比率) 算；最低 = 最高只写一个值，全为 0 写 --，不带来源。
  • 排序按钮：选了大类时才可点，调整该大类内的顺序（现有接口，传查询栏的大类）；没选时置灰，悬停提示「先在查询栏选择充值大类，再调整该大类内的排序」。首条的上移 / 置顶、末条的下移 / 置底置灰。
  • 开关、删除仍对整条通道生效，确认框列出所挂大类名称。
02列宽（充值、提现通道列表）
  • 默认宽度：按表头和当前页内容最宽的给；「充值大类」列按相邻两个大类最长的一对给。
  • 表头右边缘可拖宽、拖窄，最小 60px；放不下的内容省略，悬停看全。
  • 手动宽度沿用现有列设置存储；列设置版本号升一版。
03充值通道新增 / 编辑弹窗
  • 只改布局：拆成左右两栏，「自动切换通道」放底部整行；字段、联动、校验、接口都不变（含现有的：切换商户 / 三方映射码时清空大类和前台显示名称；动态编码通道的编码必填）。
  • 新增时：选了通道名称且前台显示名称为空，自动填通道名称（超过 20 字截前 20 字）；不为空不动。编辑时不填。
  • 「生效奖励」显示同 01。
04新增通道默认金额区间（充值、提现）
  • 新增时按商户币种预填：INR 充值、提现都是 100 ~ 100000；其他币种暂用充值 1 ~ 5000、提现 10 ~ 30000（运营给值后改前端对照表）。不看通道币种。
  • 切换商户时，金额没手动改过就按新商户币种重填，改过的不覆盖。
  • 编辑不预填；复制时用来源通道的区间。
05复制到其他商户（充值、提现通道）
  • 列表操作列「复制到其他商户」，有新增通道权限才显示。打开新增弹窗，带出来源通道配置，可修改：
    · 充值：通道、前台显示名称、三方通道编码、轮询权重、可见充值等级、可用时间段、充值金额区间、手续费率、通道手续费、充值通道奖励、备注；不带自动切换通道；状态默认「禁用」。
    · 提现：通道、出款显示名称、三方通道编码、自动出款权重、自动关闭阈值、提现金额区间、是否整百提现、通道手续费、备注；状态默认「关闭」。
  • 目标商户多选：同集团、同币种、当前账号有权限，不含来源商户。
  • 点「确定」先弹预检表，每个商户一行：「挂载大类」按名称完全一致预选，可改选；选项按现有可挂规则（三方法币、ArUpi 通道可多选，其余单选；提现单选）；没选大类时标红。
  • 预检只判断三种跳过：已有同一条三方通道（同三方商户号 + 同通道字典）、显示名称已存在、未选大类；其余「将新增」。全部跳过时不能提交。
  • 提交后逐个商户新增（走现有接口和校验），互不影响、不回滚；结果列出成功数、失败数及失败原因。
  • 充值奖励统一用弹窗设置；自定义奖励时输一次谷歌验证码，对本次所有商户生效。
06下单限制（充值大类）
  • 弹窗「下单限制」卡：「会员最大待支付单数」不变；新增「连续未支付限制」：笔数 N、暂停分钟 X，默认 0 = 不启用；本地大类不显示。
  • 列表：在「会员最大待支付单数」列后新增「连续未支付限制」列，显示「连续 N 笔 / 暂停 X 分钟」，未启用或本地大类写 --。
  • 保存校验：N、X 为整数，同为 0，或 N 在 1~99、X 在 1~1440。
  • 计数：按商户 + 会员 + 充值大类；三方下单成功（拿到付款信息）记 1 笔，含仍在待支付中的；一笔订单只记 1 次（含自动切换备用通道）；下单失败、代收测试不记。原子递增，并发也不能超 N。上线从 0 计，不追溯。
  • 触发：计数达到 N 时，该会员在该大类暂停下单 X 分钟（第 N 笔正常出单）；暂停期间下单直接失败，提示「通道繁忙，请稍后再试或更换其他支付方式」，不走备用通道，其他大类不受影响。
  • 清零：会员任意一笔充值到账（任何大类；人工充值不算）→ 所有大类计数清零、暂停解除；暂停开始时计数清零；距该大类上次下单超过 24 小时清零。
  • 拦截位置：和「会员最大待支付单数」同一处，在 V1 前台 API 写预订单之前，被拦时不生成订单；V1 新增对应错误码和多语言，不能显示成「订单失败」。
  • 缓存读写出错时放行。
  • 改配置：已在暂停中的按原结束时间；改成 0 立即不再拦截。
  • 测试会员同样生效；充值自动权重开或关都生效；不做查看、解除被暂停会员。
07快捷金额（充值大类、提现大类编辑弹窗）
  • 「从其他大类复制」：选商户（本商户或同集团、同币种、有权限的）+ 关键字筛大类（包含匹配，不区分大小写，不含本大类）；点选后用它的快捷金额整体替换现有金额。
  • 充值可勾「连同赠送设置」：勾上全部用来源的；不勾只用金额，金额相同的行保留原赠送，其余为「赠送比率 0」。
  • 粘贴拆分：在金额框粘贴多个金额时，按中英文逗号、空格、顿号、分号、换行拆开，去掉非数字、≤ 0 和重复的，从这一格起依次覆盖填入，格子不够自动新增，超过上限（充值 12、提现 8）的不填并提示；赠送同「不勾」。
  • 点「确定」才保存，沿用现有接口和校验。
  • 提现大类：每格可单独删除，「+ 新增金额」在格子下方。
08提现通道列表
  • 排序按钮一直可点（需编辑权限）：和当前列表相邻行换位，置顶 / 置底移到最前 / 最后；筛选了提现大类时只在该大类内移动；首条、末条对应按钮置灰。
  • 列表按排序值、再按创建时间倒序。排序不影响自动出款。
  • 「成功率统计」拆成「今日已提交」和「近1小时成功笔数」（数据不变）两列。
    「今日已提交」：该通道下状态为「等待第三方出款」、提交三方时间在商户时区今天、正式会员的提现单；笔数 = 单数，金额 = Σ(申请金额 − 手续费)，按法币，千分位 + 币种小数位；实时查询，失败显示 --。
09提现通道弹窗、提现大类弹窗
  • 只改布局：改成左右一屏，字段、联动、校验、接口都不变。
  • 提现通道新增：出款显示名称自动填同 03，金额区间按 04 预填。
10IFSC风控管理（集团级）
  • 集团下有 INR 商户才显示页签，能看提现通道页的账号都能看到；规则按集团，不随查询栏商户变化。
  • 规则 = IFSC + 三方通道（通道字典），集团内唯一；可选通道为本集团 INR 商户下、内置提现大类为「银行卡」的三方通道。
  • 新增：选一个通道（必选）+ 批量输入 IFSC（逗号、空格、换行、分号分隔）；保存时转大写、去重，格式须为 4 位字母 + 0 + 6 位字母或数字；格式不对、已存在的跳过，保存后提示新增几条、跳过哪些；全部跳过时不保存。
  • 列表按添加时间倒序；IFSC、限制通道名称、三方映射码按包含匹配；支持单条、批量删除，立即生效。
  • 生效对象：INR 商户带 IFSC 的银行卡提现单，比较时不区分大小写。
  • 审核「出款通道」下拉：命中的通道置灰，写「该 IFSC 受限」；所有提交三方的路径（含 FastUPI KYC 重提）提交前再校验，命中不提交，提示「该 IFSC 受限，不能提交到此通道」。
  • 自动出款排除命中的通道，没有可用通道时按现有逻辑回人工池；已提交三方的单不受影响。
  • 权限：能管本集团全部 INR 商户的账号才能新增、删除，否则按钮置灰并提示「需有本集团全部印度商户的权限」，后端同样校验。
11切换商户不清空通用查询条件（充值、提现通道列表）
  • 切换后按新商户自动查询。保留：三方映射码、通道币种、状态、充值通道的「通道ID/名称」输入框。
  • 清空：充值 / 提现大类、三方商户昵称/商户号、提现通道的「通道ID/名称」下拉，提示「已清空：xx（各商户不通用）」。
