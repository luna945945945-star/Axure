一、改造页面与字段

  • 改造页面：报表管理 › 「实时数据统计报表」。沿用现有「日期 / 日期1~4 + 查询」筛选与「每 10 分钟一行、多日期并排」的表格结构，不改原有指标口径与刷新机制。
  • 新增内容：每格内每个指标行，在「数值」之后新增两个对比值 ——「环比」「同比」（13 个指标全部适用）：新增注册 / 投注用户 / 在线人数 / 首充用户 / 二充用户 / 充值金额 / 充值人数 / 三方近1小时成功率 / 三方近3小时成功率 / 提现金额 / 提现人数 / 充值差 / 优惠合计。
  • 展示辅助：顶部新增开关（环比 / 同比 / 异常高亮）与图例；单元格内首行加「数值 · 环比 · 同比」列头。

二、口径定义

维度对比基准公式用途
环比同一日期、「上一个 10 分钟时段」（表格中相邻的下一行，时间更早 10 分钟）本时段值 − 上一时段值即时趋势，抓突增突降（成功率骤降、提现骤升等）
同比「上一个筛选日期」的「同一时刻」（相邻右列，时段相同，随日期1~4变化）本列本时段值 − 上一日期列同时段值按所选日期1~4两两对比同一点位好坏
  • 涨跌与配色：对比值 >0 显示 ↑ 绿色、<0 显示 ↓ 红色、=0 灰色（沿用参考图三配色，纯按数值方向，不区分该指标「涨是好还是坏」）。
  • 成功率类（三方近1h/3h成功率）：对比 = 两个成功率之差（今值 − 基准），带 % 显示，如 71% 对 73% 记 ↓2%。口径为「差值」（本质是百分点，随值一起用 % 呈现），非相对变化率 (本−基)/基。
  • 金额/计数类：显示「绝对差值」（完整千分位数值，不用万/亿缩写）。

三、展示方式

每格「指标：数值 ｜ 环比 ｜ 同比」并列
每个指标行内，数值后并列 「环比」「同比」 两个对比（箭头 + 颜色 + 差值），四列左对齐、一屏可同时看两个维度；顶部开关可随时隐藏环比或同比降噪。涨 ↑ 绿、跌 ↓ 红、持平灰；单元格首行为「指标 / 数值 / 环比 / 同比」列头。

四、边界与规则

  • 无环比基准：当前查询时间范围内「最早的一个时段」没有上一时段，环比显示 —。
  • 无同比基准：上一个筛选日期该时刻无数据（新站点 / 早于开服，或「最后一个日期无更早所选日期」）显示 —；「未来时段」（今日晚于当前时刻的行）本无数据，环比 / 同比同样为空。
  • 同比 = 上一个筛选日期同一时刻（随日期1~4变化，非固定前一天）：今日的同比对比「日期1」、日期1对比「日期2」、日期2对比「日期3」、日期3对比「日期4」；日期可「非连续」，同比即按所选相邻日期相减。最后一个日期（日期4）没有更早的所选日期，同比显示 —。
  • 累计 vs 当期口径：若某指标是「当日累计值」（如充值金额累计），环比会恒为正（每时段只增），此时环比 ≈ 本时段新增量；同比才体现同点位对比。口径以现有报表为准，对比公式不变。
  • 显示规范：成功率的环比 / 同比按 % 显示（成功率之差，非相对变化率）；金额显示完整千分位数值（不用 万 / 亿 缩写，便于核对）；每格「数值 / 环比 / 同比」统一左对齐，指标名后带「：」。

五、验收标准

  • 字段完整：13 个指标每行均在数值后展示 「环比」「同比」 两个对比值（新增注册 / 投注用户 / 在线人数 / 首充 / 二充 / 充值金额 / 充值人数 / 三方1h·3h成功率 / 提现金额 / 提现人数 / 充值差 / 优惠合计）。
  • 环比取数正确：环比 = 本时段 − 同日「上一个 10 分钟时段」（表中相邻下一行）；抽查任一格与下一行相减一致。
  • 同比取数正确：同比 = 本列 − 「上一个筛选日期（相邻右列）」同一时段；把日期1~4 改成非连续日期后，仍按所选相邻日期计算，不得固定按前一天。
  • 涨跌与配色：对比 >0 显示 ↑绿、<0 ↓红、=0 灰；成功率对比以 % （成功率之差）呈现，金额 / 计数以完整千分位绝对差值呈现（不用 万 / 亿）。
  • 口径分型正确：累计型指标（充值 / 注册 / 提现等）环比恒为正（=本时段增量）；在线人数 / 两成功率 / 充值差 的环比、同比可正可负。
  • 边界处理：范围内最早时段的环比、最后一个筛选日期的同比、及无数据 / 未来时段，均显示 —（不报错、不显示 0）。
  • 开关生效：环比 / 同比可各自隐藏、异常高亮可开关，切换后布局不错位、整页无横向滚动条。
  • 不改原口径与机制：原有各指标数值、10 分钟统计与页面刷新均与现网一致；刷新后对比值随之重算。
