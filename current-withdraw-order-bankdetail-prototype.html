当前提现订单 · 银行卡详细列

提现订单管理 · 出款

一、改造页面

提现订单管理 →「当前提现订单」列表，在「提现大类」后新增一列「银行卡详细」（参照「全部提现记录」页同名列）。

二、业务规则

  • 取订单下单时快照的收款信息展示，无需回查会员绑定。
  • 银行卡：银行名称 / 收款人 / 账号 / IFSC / 邮箱 / 手机号 / 城市编码 / 省份编码 / 支行地址。
  • 电子钱包（EasyPaisa / JazzCash / KBZPay 等）：类型 / 收款人 / 账号（本质为手机号）。
  • USDT：仅展示 类型 / 钱包地址。
  • 脱敏只针对手机号：手机号字段、电子钱包账号（本质手机号）按权限脱敏，口径 前3位 + 三个星号 + 后3位（星号个数固定，不随长度变）。
  • 银行卡账号、UPI VPA、USDT 钱包地址、IFSC、邮箱等非手机号信息明文展示。
  • 内容较多时可折叠 / 展开。

三、限制

  • 脱敏是否需要权限查看，沿用后台现有敏感信息权限。
  • 本次仅新增「银行卡详细」列，其余列不动。
