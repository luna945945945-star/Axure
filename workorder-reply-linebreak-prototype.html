      一、改造页面
      📌 本说明书只写业务规则本身，样子和交互直接看原型，带红色「改」角标的是本次改动的位置。
      页面改动点
      工单管理端 → 工单管理 → 工单详情弹窗右侧客服与会员的对话气泡里，回复内容按输入时的换行显示
      工单详情 → 历史一对一工单 → 历史工单详情弹窗回复内容按输入时的换行显示
      会员端 → 进度查询 → 工单卡片客服备注按输入时的换行显示；仍默认折叠 3 行，展开后逐行显示
      会员端 → 进度查询 → More Reply 弹层客服和会员的回复内容按输入时的换行显示
      二、功能描述与业务规则
      🎯 核心结论
      回复和备注怎么敲的就怎么显示：换行、空行、连续空格全部保留，后台和会员端一致
      只改显示；输入方式、保存的内容、接口全部不动
      过长的链接、订单号在显示区域内自动折行，手机上不出现横向滚动
      01原样换行显示核心：客服在工单详情「备注」框输入的内容，含点快捷回复填入的模板，提交后在上述四个位置按输入时的换行显示，开头和结尾多敲的空行也原样显示，不做任何裁剪；会员在会员端回复框输入的内容同样处理。
      02长内容折行核心：正常的词句照常在空格处换行；只有一整段没有空格、一行放不下的长串（链接、订单号）才在放不下的位置断开，不撑宽弹窗、弹层和页面。
      03会员端卡片折叠照旧：沿用现有的 3 行折叠，不另做。「3 行」按屏幕上实际显示的行数算，敲回车换出来的行和自动折出来的行都算；超过 3 行时默认只显示 3 行并出现「展开」，展开后全部显示，「收起」回到 3 行。
      04标签字符按文字显示：回复里出现的网页标签字符（如 <b>）原样显示为文字，不生效为格式。
      三、限制条件
      项说明
      范围只改上述四个显示位置；编辑回复弹窗里的输入框不涉及
      不做不改回复的保存格式；不加富文本；回复里的链接不做成可点击；不改快捷回复模板的录入和内容
      多语言各语言版本一致，不做任何语言差异处理
      四、开发注意事项
      1. 两端都只改显示样式：给四个显示位置的文字加「保留换行、允许折行」的文本样式即可；接口、保存内容、输入框都不动。
      2. 继续按纯文本显示，不要把换行转成网页标签再当网页内容渲染，否则会员输入的标签字符会被执行。
      3. 会员端卡片的备注用的是三行省略组件，加样式后要实测「展开 / 收起」的行数算得对不对、折叠高度是不是整行。
      4. More Reply 弹层里「Support / you」标签列宽度固定，内容列要允许收缩，不然长链接会把弹层撑宽。
      5. 后台和会员端一起发版；只发一端会出现后台看得到换行、会员端看不到的情况。
      6. 自测用一条带 7 条编号、带一个长链接、末尾多敲两个回车的回复，四个位置各看一遍：编号各占一行、链接折行且页面不横向滚动、末尾空行照样显示、会员端卡片能展开收起；再切阿拉伯语看一遍，编号仍逐行。
