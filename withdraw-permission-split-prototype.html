需求编号 WITHDRAW-PERM-001  |  适用系统 V1 后台

一、新增权限项

权限显示名动作码对应按钮 / 接口
人工确认withdrawconfirm人工确认 → WithdrawalExamineState（类型=8 且 State=1）
三方出款（审核）withdrawthirdpay各三方通道按钮 → WithdrawalExamineState（类型≠8）
确认取消withdrawreject确认取消 → WithdrawalExamineState（类型=8 且 State=2）
异常消除withdrawexception异常消除 → WithdrawalThridPartCancel（现状无鉴权）

二、移除的动作码

确认审核:audit、修改:update、确认取消(所有人):cancelall、确认审核(所有人):auditall、取消审核(所有人):notauditall —— 代码从未校验，勾选不产生任何效果。

三、业务规则

  1. 四个权限相互独立，可任意组合授予。
  2. 确认取消（人工拒绝）执行后提现金额退回会员余额，退款逻辑不改动。
  3. 三方出款不按通道细分，持有该权限即可使用全部已启用通道。
  4. 订单锁定人限制不变，权限校验是锁定人校验之后的第二道闸，两者都通过才放行。
  5. 超管（IsSuperAdmin）不受四个权限约束。
  6. 提现出款四个权限全无时，操作列整列不渲染。
  7. 「刷新确认」（RefreshWithdrawState）本期不动，接口维持无鉴权、按钮维持无显隐控制。
上线必做：withdrawalmanitou:audit 拆分后不再被任何代码校验，须执行存量角色订正 SQL 把旧权限展开为新权限，否则出款停摆。Authority 格式为 |a:b|c:d|，相邻项共用一个竖线。完整脚本见 withdraw-permission-split-prd.md 第三节。
