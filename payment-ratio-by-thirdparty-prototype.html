二、名词术语
术语说明
三方即「三方映射码」（如 ArbPayINR），就是页面「三方」筛选里的选项；不是三方商户号
通道商户通道。同一个三方通道给两个商户用，算 2 个通道
统计口径和现有页面一样：只统计走三方通道的订单；日期按商户所在时区的自然日算
成功金额 / 成功笔数和现有页面一样，按成功时间统计；代收金额按实际到账金额
创建金额 / 创建笔数仅代收。下单的金额和笔数，不管最后成没成功，按下单时间统计；和通道报表用同一份数据
成功率仅代收。成功笔数 ÷ 创建笔数，算法和通道报表一样。创建按下单时间、成功按成功时间算，跨天的订单会让个别数值超过 100%，按实际值显示，不封顶。创建笔数为 0 时显示「—」
金额占比 / 笔数占比该三方的成功金额（笔数）÷ 全部三方的成功金额（笔数）。“全部三方”指按国家/币种、日期、集团、商户查出来的所有三方，不管「三方」「通道名称」选了什么（见第 02 条）
手续费和现有页面算法一样：成功金额 × 费率 + 成功笔数 × 每笔固定手续费，每天按当天的费率算。是系统按配置算出来的，不是三方实际扣的钱
已配置费率费率、每笔固定手续费有一个不为 0 就算配置了，判断方法和现有页面一样；每天单独判断
综合费率该三方的手续费 ÷ 该三方配置了费率的那部分成功金额。因为算上了每笔固定手续费，可能比通道上配的费率高
对比期（环比）是环比，不是同比。由查询时点的日期快捷按钮决定和哪段时间比（见第 11 条），其他筛选条件不变。“同期”指截到同一天的同一时刻：例如今天 10:30 点「今天」查询，对比期是昨天 0 点 ~ 10:30
数据起始日本页的按天统计数据从「代付/代收占比」页上线生产那天开始累计，之前的日期没有数据，这次也不补。数据起始日 = 统计数据里最早的那一天（不分币种、商户），系统自动取，不加配置项
三、功能描述与业务规则
01切换查看方式：操作按钮那一行加「按三方汇总 / 通道明细」切换按钮。每次打开页面默认是「按三方汇总」，不记上次选的。切换时筛选条件不变，排序和页码回到默认。切换代收 / 代付页签时，查看方式不变。
02筛选条件怎么影响「按三方汇总」：
· 国家/币种、日期、集团、商户：决定统计哪些数据，卡片、列表、占比都跟着变。
· 三方、通道名称：只用来在列表里挑出要看的行。卡片不变，占比的分母也不变（仍是全部三方）。
例：9-29 全部三方代收成功 1,000 万，其中 ArbPay 700 万（它的通道 A 400 万）。
· 不选三方：列表显示所有三方，ArbPay 占比 70%，卡片成功金额 1,000 万；
· 三方选 ArbPay：列表只剩 ArbPay 一行，占比还是 70%，卡片还是 1,000 万；
· 再选通道 A：ArbPay 这一行只算通道 A，成功金额 400 万、占比 40%，商户数、通道数也只算通道 A；卡片还是 1,000 万。
03汇总卡片：放在筛选区和操作按钮下面、列表上面。代收 8 项：三方数、商户数、创建金额、创建笔数、成功金额、成功笔数、成功率、手续费；代付 5 项：三方数、商户数、成功金额、成功笔数、手续费。三方数、手续费右边有问号提示，文字照原型。
04卡片对比：能对比时（见第 11 条），每张卡片下面显示对比期的名称和数值（如「昨日同期 12,000.00」），再显示增减（差多少、变化百分之几；成功率显示差几个百分点）。增减为 0 显示「持平」；对比期为 0 时只显示差多少，不显示百分比。增加显示绿色、减少显示红色，只表示涨跌，不代表好坏。卡片下面用一行灰字写出对比日期或不对比的原因，灰字最后带问号提示，说明对比口径，文字照原型。
05列表列：统计日期、三方、商户数、通道数、成功金额、成功笔数、成功率（仅代收）、金额占比、笔数占比、综合费率、手续费、手续费占比。一个三方一行。「统计日期」显示所选的日期范围（如 2026-09-25 ~ 2026-09-29），不按天拆成多行；中途改过费率也不拆行（通道明细会拆，这里不拆）。数字格式和现有页面一样。
06三方数、商户数、通道数（卡片和列表都是）：只数有订单的。代收：有下单就算，全部失败的也算；代付：有成功出款才算。对比期的三方数、商户数也按这个口径数。
07手续费三列（综合费率、手续费、手续费占比）：手续费只加配置了费率的部分。一个三方完全没配费率 → 三列都显示「—」；配了费率但那部分成功金额是 0 → 综合费率显示「—」。全部失败的三方看第 10 条。
08排序：默认按成功金额从高到低。可以点表头排序的列：成功金额、成功笔数、成功率（仅代收）、手续费。排序是对全部数据排，不是只排当前这一页；显示「—」的当 0 排；数值一样时按三方名称 A→Z 排。
09查看通道明细：点三方名称，切到「通道明细」，三方筛选自动选上这个三方，通道名称筛选清空，其他筛选不变。全部失败的三方名称点不了（见第 10 条）。
10全部失败的三方也要显示（仅代收）：有下单、但一笔都没成功的三方，也要显示一行：成功金额、成功笔数、金额占比、笔数占比都是 0；成功率 0.00% 标红；手续费 0.00、手续费占比 0.00%；综合费率「—」；名称后面加「无成功订单」标签；三方数要算上它。只有成功率为 0 的才标红。通道明细只统计成功的订单，这类三方在那里没有数据，所以名称点不了。
11什么时候对比、和谁比：只有用日期快捷按钮查询时才对比，按最后一次点的快捷按钮决定对比期：
· 今天 → 昨日同期：昨天 0 点到昨天的同一时刻（如 10:30 查询，比昨天 0 点 ~ 10:30）
· 昨天 → 前日：前天整天
· 本周 → 上周同期：上周一 0 点到上周同一天的同一时刻（一周从周一开始，和现有日期控件一致）
· 上周 → 上上周：上上周一到周日整周
· 本月 → 上月同期：上月 1 日 0 点到上月同一天的同一时刻；上月没有这一天（如 3-31 查询，2 月只有 28 天）就比到上月最后一天整天
· 上月 → 上上月：上上月整月，天数不同也不折算
不对比的情况：手动选的日期（包括点了快捷按钮后又手动改日期）；对比期有一天早于数据起始日。这时卡片只显示当前值，灰字写明原因，不要显示 0、-100% 或「—」占位。
日期范围相同的按钮按点的那个算（如周一时「今天」和「本周」都是当天，点「今天」比昨日同期，点「本周」比上周同期）。页面默认的“今天”算作点了「今天」，点「重置」后也回到「今天」。“今天”“同一时刻”按页面日期控件的时区，和现有一致。
12导出：导出当前所在的查看方式。在「按三方汇总」下导出：列和行跟列表一样（包括全部失败的三方），不导出卡片。用现有的导出权限。
13通道明细：列、数据、占比算法、卡片（总额 / 三方数 / TOP3）都不变，只把卡片挪到筛选区和操作按钮下面。注意：通道明细的占比还是按现有逻辑，选了三方或通道后分母会跟着变，所以选了这两个筛选后，两种查看方式的占比可能不一样，这是正常的。
14其他照旧：日期快捷按钮、「自定义列」、分页都用现有的，对当前查看方式的列表生效。
