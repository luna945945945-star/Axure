搜索主菜单 + 子菜单 本次重点

  • 搜索同时匹配主菜单名和子菜单名，深藏的二级页面也能一键搜到。

  • 本地保存（真实落地按登录账号存，各管各的）。
PRD · 后台菜单搜索与常用收藏
一、改造页面与字段
  • 改造对象：后台侧边栏（全站后台通用左侧菜单栏），不改菜单数据结构、不改现有菜单管理功能。
  • 侧边栏顶部新增 菜单搜索框。
  • 每个主菜单 / 子菜单行，悬停时右侧新增 收藏星标。
  • 侧边栏顶部新增 常用菜单 分组，用于展示已收藏项。
  • 不新增业务表；常用收藏按登录账号存储（每个管理员一份，互不影响）。
二、功能与规则 — 搜索
  • 搜索范围 = 当前账号有权限的主菜单名 + 子菜单名；无权限的菜单搜不出来（与菜单权限保持一致）。
  • 匹配方式：包含匹配、大小写不敏感；支持拼音 / 首字母（如输 upi、xtip）。
  • 结果以 「主菜单 › 子菜单」 面包屑展示，命中文字高亮；一级菜单命中时带出其下全部有权限子项。
  • 点击结果 直接跳转对应页面（使用该菜单已配置的跳转地址）。
  • 无匹配显示空状态；清空搜索框恢复原菜单树。
三、功能与规则 — 常用收藏
  • 主菜单、子菜单均可收藏；点星标加入，再点取消。
  • 已收藏项置顶到「常用菜单」分组，子菜单以「主 › 子」显示，可一键直达深层页面。
  • 收藏数据按登录账号存储，一个管理员的调整不影响其他人。
  • 常用为空时显示引导提示；常用项的跳转与其在菜单中的跳转一致。
四、限制与边界
  • 只做「搜索 + 常用收藏」，不含拖拽调整菜单位置（菜单位置仍由菜单管理页统一维护，全局生效）。
  • 搜索与收藏全程受菜单权限约束，前后端一致，不得暴露无权限菜单。
  • 某菜单被删除 / 停用 / 失去权限时，其在常用中的收藏项自动不再显示。
