一、改造页面

页面改动点

二、功能描述与业务规则
🎯 核心结论
有投注量、但会员当前 VIP 等级的洗码率为 0，算出的返水为 0 → 提示「Your current VIP level has no rebate. Upgrade your VIP level to get rebates.」
其他领不到返水的情况，仍提示原来的「Wash code is not enough」
01触发条件核心：点 One-Click Rebate 后，本次领取范围内有投注量，但按会员当前 VIP 等级，有投注量的游戏类型洗码率都是 0，算出的返水为 0 时，显示新提示。选 All 时看参与领取的全部游戏类型，选单个游戏类型时只看该类型；只要有一类算出的返水大于 0，就照常领取。
02按配置判断核心：以会员当前 VIP 等级在后台配置的洗码率为准，不限定 VIP0；哪个等级的洗码率为 0，该等级的会员就会看到新提示。
03提示样式：沿用现有报错样式，显示新的错误编号和新文案。
04多语言：英文为「Your current VIP level has no rebate. Upgrade your VIP level to get rebates.」，中文为「您当前的VIP等级暂无返水，升级VIP等级即可获得返水」；其他语种没有译文时显示英文。
三、限制条件
项说明
适用范围全站前台 Rebate 页的 One-Click Rebate
本次不做不改洗码率、领取门槛和返水计算规则；凌晨自动洗码不涉及
四、开发注意事项
  1. 新增一个提示（新的错误编号），不要改原「Wash code is not enough」的文案和触发条件，其他领不到的情况仍走原提示。
  2. 选 All 时体育不参与领取，判断「有投注量的类型洗码率都为 0」时也不算体育。
  3. 服务端自带的默认英文提示也用同一句新文案；前台语言包要加这个新编号的词条。
  4. 服务端和前台一起上线；只上服务端时，前台会直接显示服务端的英文提示。
